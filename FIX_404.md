# Fix 404 on tempestiq.com

**PowerShell note:** If you run commands manually in PowerShell, use `;` instead of `&&` (e.g. `npx prisma generate; npx next build`). The scripts in `package.json` now use `npx` so `npm run build` and `npm start` should work after `npm install`.

---


If **https://tempestiq.com** (or https://www.tempestiq.com) shows a **404 error**, use these checks.

---

## 1. Try the marketing page directly

Open:

**https://tempestiq.com/marketing**

- If **this works** but the root (https://tempestiq.com) 404s, the app is deployed and the issue is only the root redirect. Skip to **4. Root redirect** below.
- If **this also 404s**, the problem is deployment or domain (steps 2–3).

---

## 2. Check Vercel deployment

In **Vercel Dashboard** → your project → **Deployments**:

- Is there a **Production** deployment with a **green checkmark** (Ready)?
- If the latest deployment **failed** (red X), the site can 404. Click the failed deployment → **Building** / **Logs** and fix the error (e.g. build or env failure).
- If there are **no deployments**, push to `main` and wait for the build to finish.

**Common build failures:**

- **Prisma:** If the build fails on `prisma generate`, set **Build Command** in Vercel to:  
  `npx prisma generate && next build`  
  (or keep using `npm run build` and ensure Prisma is in `dependencies`, not only `devDependencies`.)
- **Missing env:** Add required env vars in Project → **Settings** → **Environment Variables** (e.g. `DATABASE_URL` if the build needs it).

---

## 3. Check domain assignment

In **Vercel Dashboard** → your project → **Settings** → **Domains**:

- Is **tempestiq.com** (and **www.tempestiq.com** if you use it) listed for **this** project?
- If the domain is on a **different** project (or none), move it to this project or add it here. Only the project that has the deployment should have the domain.

---

## 4. Root redirect (if /marketing works but / 404s)

The app is set up so **/** redirects to **/marketing**. If only the root 404s:

- Try opening **https://tempestiq.com/marketing** and bookmark that, or
- We can add a fallback (e.g. static root page with a link to /marketing) so **/** always shows something.

---

## 5. After fixing

- Push a small change and wait for a new **Production** deployment to finish.
- Hard-refresh the site (Ctrl+F5 or Cmd+Shift+R) or try in an incognito window so you don’t see an old cached 404.
